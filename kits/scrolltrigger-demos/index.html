ScrollTrigger demos

Three pages showing start and end with the markers on. Open one, scroll slowly, and watch where the markers meet.

  1. Arrive: start: "top 80%". The heading plays on its own once its top edge reaches 80% down the screen.
  2. Scrub: start: "top 80%", end: "top 40%", scrub: true. Your scrolling drives the heading between the two.
  3. Try the values: change both values of start and end and watch the markers move.

Open the files in a browser and read the code in a code editor. They need an internet connection: GSAP loads from jsDelivr.
