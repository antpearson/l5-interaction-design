6 Drag the bar

Grab the white bar on the picture and drag it. The postcard follows it. It is demo 5's slider, but the reader drags the picture itself.

Three listeners: press on the bar, move, let go. The slider stays as well, because some readers cannot drag: it does the same job from the keyboard.

Beat 01: drag the bar

Granby Street about 1903, and the same corner in 2009. Drag the white bar to move between them.

Keep a slider or buttons beside anything the reader drags. Dragging shuts out keyboard users and some people who cannot hold a mouse button down.

The code

In index.html, inside the held picture:

<div id="divider">
  <span class="grip" aria-hidden="true">&lsaquo;&rsaquo;</span>
</div>

In js/main.js:

let dragging = false;  // let: it changes

divider.addEventListener("pointerdown", function (event) {
  event.preventDefault();
  dragging = true;      // 1 press on the bar
});

window.addEventListener("pointermove", function (event) {
  if (dragging) {         // 2 move, while pressed
    const box = held.getBoundingClientRect();
    showAt((event.clientX - box.left) / box.width * 100);
  }
});

window.addEventListener("pointerup", function () {
  dragging = false;     // 3 let go
});

showAt() is a function: a few lines with a name, so the bar and the slider can both use them. It is at the top of js/main.js.

Drag something else

To drag a marker along a line instead, give it the bar's CSS (position: absolute, touch-action: none) and change one line in showAt(): 

marker.style.left = percent + "%";

event.clientX is how far across the screen the pointer is. Take away where the picture starts, divide by its width, and you have how far across the picture it is.

End of the demo.
