5 Slider

Drag to compare 1903 and 2009, one photo cut away over the other. The slider is an <input type="range">, which the browser draws for you. It works with a mouse, a finger and the arrow keys.

It listens for "input" instead of "click": the slider sends it every time it moves.

Scroll down to the picture.

Beat 01: a slider

Granby Street about 1903, and the same corner in 2009. Above the signs, almost nothing has changed.

The code

In index.html, inside the beat:

<label for="slider">Slide right for more of 1903</label>
<input type="range" id="slider"
  min="0" max="100" value="50">

In js/main.js:

const slider = document.querySelector("#slider");
const then = document.querySelector("#pic-1900s");
const divider = document.querySelector("#divider");

slider.addEventListener("input", function () {
  // slider.value is a number from 0 to 100
  then.style.clipPath =
    "inset(0 " + (100 - slider.value) + "% 0 0)";
  divider.style.left = slider.value + "%";
});

Move something along instead

To move a marker along a line, rather than cut a picture away, set its left from the slider, as the divider does here. Give the marker position: absolute inside the line. 

marker.style.left = slider.value + "%";

End of the demo.
