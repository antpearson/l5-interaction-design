3 Choice

Two buttons, two outcomes. Each button shows its own outcome and hides the other, and both bring in a marker on the picture.

A choice like this is the clearest kind of interaction: a different reader can choose differently.

The code

In index.html, inside the beat:

<button type="button" id="choose-pool">A swimming pool</button>
<button type="button" id="choose-cinema">A cinema</button>

<div aria-live="polite">
  <p id="outcome-pool">No pool. …</p>
  <p id="outcome-cinema">Yes. …</p>
</div>

In js/main.js:

const outcomePool = document.querySelector("#outcome-pool");
const outcomeCinema = document.querySelector("#outcome-cinema");
outcomePool.hidden = true;
outcomeCinema.hidden = true;

const marker = gsap.from("#marker-1915", {
  opacity: 0, scale: 0, duration: 0.5,
  ease: "back.out(2)", paused: true
});

document.querySelector("#choose-pool")
  .addEventListener("click", function () {
    outcomePool.hidden = false;   // show this one
    outcomeCinema.hidden = true;  // hide the other
    marker.play();
  });

document.querySelector("#choose-cinema")
  .addEventListener("click", function () {
    outcomeCinema.hidden = false;
    outcomePool.hidden = true;
    marker.play();
  });

aria-live reads the outcome out to screen-reader users when it appears.
