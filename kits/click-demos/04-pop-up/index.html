4 Pop-up

A button opens a box over the page, with more than the beat has room for. It is an HTML <dialog>, and the browser does most of the work: Esc closes it, and the page behind cannot be clicked while it is open.

The last beat is a fold-out: a <details>. That one needs no script at all.

Scroll down to the picture.

Beat 01: a pop-up

Granby Street, 2009. A postcard shows the same corner about 1903.

Granby Street, Leicester, on a postcard from about 1903. The Grand Hotel is the tall building on the left.

The <dialog> stays shut until the script opens it. With no script it never opens, so nothing your story needs should be only in a pop-up.

The code

In index.html, inside the beat:

<button type="button" id="open-postcard">Open the postcard</button>

<dialog id="postcard">
  <img src="images/…" alt="…">
  <p>Granby Street, about 1903.</p>
  <button type="button" id="close-postcard">Close</button>
</dialog>

In js/main.js:

const postcard = document.querySelector("#postcard");

document.querySelector("#open-postcard")
  .addEventListener("click", function () {
    postcard.showModal();
  });

document.querySelector("#close-postcard")
  .addEventListener("click", function () {
    postcard.close();
  });

Beat 03: a fold-out, no script

By 2009 the Grand was a Ramada.

Ramada

A brand of hotels. By 2009 the Grand was one of them.

Good for a word that needs explaining, or a glossary. It works with no script, so with JavaScript off the reader can still open it. 

<details>
  <summary>Ramada</summary>
  <p>A brand of hotels. …</p>
</details>

End of the demo.
