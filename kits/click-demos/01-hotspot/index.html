Beat 01: three hotspots

Granby Street, Leicester, 2009. The tall building is the Grand Hotel. Click a year to see what happened behind its windows.

Each year is a <button> on the held picture. Each note is a plain <p> that the script hides as the page loads.

The code for one hotspot

In index.html, inside the held picture:

<button type="button" id="button-1898"
  aria-expanded="false">1898</button>
<p id="note-1898">The Grand Hotel opens.</p>

In js/main.js:

const button1898 = document.querySelector("#button-1898");
const note1898 = document.querySelector("#note-1898");

note1898.hidden = true; // no script, no hiding

button1898.addEventListener("click", function () {
  note1898.hidden = !note1898.hidden;
  button1898.setAttribute("aria-expanded", !note1898.hidden);
});

1909 and 1915 are the same block, with their own ids.

Why the clicks reach the picture

In css/style.css. The beats sit in front of the held picture, so they would catch every click. These two lines let clicks through the empty space in a beat. Anything inside the beat still catches its own. 

.beat { pointer-events: none; }
.beat > * { pointer-events: auto; }
